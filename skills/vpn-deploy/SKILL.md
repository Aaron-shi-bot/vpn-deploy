# VPN 搭建与排障

将用户从当前进度带到“目标应用实际走预期出口，节点能独立管理和撤销”。默认结构是本机 v2rayN 直连单台 Linux VPS，由该 VPS 提供最终出口；3x-ui 在这台 VPS 上管理 Xray，协议组合为 VLESS + REALITY + Vision。3x-ui 不是额外中转节点。这是代理节点方案，通过应用代理、系统代理或按需 TUN 覆盖相应流量。已有其他 VPS 时继续使用，不要求更换商家。

## 先确定任务与进度

- 用户只要方案、教程或 skill 时，制作所需资料；这不授权连接服务器或修改本机网络。
- 用户要求实际部署时，在已授权的服务器、端口和改动范围内推进，不重复询问已给的信息。已有节点只排障或补齐缺项，不重新安装。
- 用户只问多人分享时，直接进入“客户端与分发”，无需重新购买或部署。
- 用会话、面板只读信息确定：VPS 地址及实际 SSH 端口、OS/架构、是否已有 3x-ui/Xray、客户端 OS/版本、当前症状。只问影响下一步的缺项，不索取完整密码、私钥、API Token、订阅链接截图。
- 若“VPN”指内网组网、访问 NAS 或站点互联，先明确用途，不强行套用本代理流程。

## 工作顺序与参考资料

完整搭建读取 [部署流程](references/deployment.md)，从已完成的阶段继续。具体故障或多人分享读取 [排障与分发](references/troubleshooting.md)。讨论单台直连、中转、Claude/Codex 应用覆盖或账号风险时读取 [架构与使用边界](references/architecture.md)。核对旧教程、字段变更或价格承诺时读取 [来源与修正](references/sources.md)。

1. **准备与登录**：使用已知 SSH 端口，只测试指定目标；读系统版本、内存、swap、监听端口及现有服务。将部署参数与秘密分开记录。
2. **基础环境**：按实际需要更新依赖；保留有效 SSH/云初始化配置并检查差异。swap、BBR 按需设置，先检查现状。时区默认保持原值。
3. **面板与管理入口**：核对官方稳定版本后安装 3x-ui，避免再装第二个独立 Xray 服务。管理使用有效 HTTPS 或受限的 SSH 隧道；区分面板、节点及证书验证端口。
4. **入站**：创建 VLESS / RAW（旧版 TCP）/ REALITY。本路线选择 Vision，两端均设 `xtls-rprx-vision`。目标站按当前内核要求实测，生成新密钥及非空 Short ID，不复制原聊天配置。
5. **客户端与分发**：辨认实际版本的入口。生成独立 UUID，明确关联到目标入站；启用后只导出属于该人的链接或专用订阅，核验数量和关联关系。
6. **Windows 客户端**：从 v2rayN 官方发布页按架构与运行库需求选包，核对发布校验信息，导入单客户端配置，选为活动节点，再设置所需代理模式。
7. **分层验收**：检查服务、指定端口、REALITY 握手、代理出口及目标应用实际请求。仅端口开放或显示在线不足以宣布完成。
8. **交付与回滚**：报告版本、端口用途、非敏感参数、实测证据及未测项，说明停止代理、恢复改动及撤销单个客户端的方法。

给新手每次提供一小段操作、预期结果和下一步。能读当前界面时先读；界面不同就查实际版本文档或索取不含秘密的局部截图，不反复猜按钮或要求滚动不存在的区域。

## 不可丢失的约束

- 不扫描端口来代替查看服务商面板；不重装已有系统来解决普通连接故障。
- 改防火墙或 SSH 前保留可用会话和控制台入口，允许实际 SSH 端口并用第二个连接验证；不清空全部规则或关闭防火墙。
- 不把公网 HTTP 管理、忽略证书告警、`curl -k`、停用防护作为常规解决方案。有效 IP 证书可以被信任；告警需检查 SAN、证书链、有效期与时间。
- 面板密码/Token、REALITY 私钥、UUID、订阅 Token 不进 skill、仓库、公开报告或记忆。发现原材料暴露凭据，提醒所有者轮换，不自行登录或自动替换。
- 保持当前 Xray/3x-ui 的唯一配置来源；面板管理的配置不另写一份手工 JSON 覆盖。
- 版本、包名、价格/库存、续费和换 IP 政策实时核对；不能把“住宅 IP”“零风险”等描述当验收标准。
- VPS 只转发流量与运行开发构建是不同负载，不能用本地仓库大小推导代理服务器内存要求。
- 已授权部署不反复确认。购买、系统重装、替换正在使用的全局凭据、扩大分享范围，仅在用户授权涵盖时执行，并遵守工具自身的确认边界。

## 离线链接检查

需要检查导出字段或单设备误收多个凭据时运行：

```text
python scripts/check_vless.py --input <本地私密链接文件> --expect-count 1
```

路径相对本技能目录，也支持标准输入。仅检查本路线 REALITY + Vision 的普通文本/Base64 VLESS 订阅；不抓取订阅 URL、不上传、不回显秘密。YAML/JSON 订阅应由相应客户端查看。检查结果可分享，原文件仍须保密。

通过仅表示格式正确，不能证明密钥配对、服务在线、目标可用或应用走了代理。有效的非 Vision 配置不适用此检查器。同一用户跨多个入站复用 UUID 的合法配置也不适用其“重复 UUID”分发检查，需按授权关系另行核对。

## 最终验收表

| 层次 | 需要说明的证据 |
| --- | --- |
| 管理 | 管理入口方式、证书验证或隧道方式；秘密由用户妥善保存 |
| 服务 | 实际版本、入站监听与进程；客户端启用并正确关联 |
| 连接 | 真连接测试及错误变化，不是仅 ICMP ping |
| 出口 | 显式代理请求得到预期出口；IPv4/IPv6、DNS 按模式检查 |
| 应用 | 目标应用实际请求成功，账户/额度问题分开记录 |
| 分发 | 每人只获得自己授权的 UUID/订阅，额度和到期可解释 |

未执行写“待验证”。只有用户反馈成功时写“用户反馈成功”，不冒称代理实测。涉及重启持久性时明确是客户端重启、服务重启还是 VPS 重启，后者不能在未授权时擅自执行。
