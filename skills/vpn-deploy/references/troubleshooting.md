# 排障与多设备分发

只定位当前失败层，保留工作的部分。每轮提出可验证假设；两次同类尝试无进展就检查其他证据，不无限重复安装/猜按钮。

## 故障定位

| 现象 | 优先检查 | 不应误判 |
| --- | --- | --- |
| SSH 不通 | 实例状态、已知真实端口、控制台中的监听及规则 | 22 不通不等于 VPS 坏了，无需扫描 |
| 升级后 SSH 不通 | 有效 sshd 配置、include 片段、服务；sshd -t 后恢复所需项 | 不覆盖全配置或停防火墙 |
| 面板根地址 404 | 协议、管理端口、完整 web base path 的大小写 | 404 不证明登录地址正确或 Xray 成功 |
| 证书告警 | SAN、链、有效期、时间、续期 | IP 证书并非都会告警，不默认忽略 |
| 登录失败 | 用户核对已保存凭据、大小写、空格、MFA，必要时恢复 | 不索要密码、不写弱密码让用户照抄 |
| Xray 不运行 | 日志、配置、端口冲突、权限、重复服务 | 面板打开不代表内核正常 |
| 客户端为 0 | 实际版本的客户端管理入口、启用及关联入站 | 建入站不等于已有访问凭据 |
| 真连接超时 | 指定端口，再对比 UUID、密钥配对、SNI、sid、Flow、时间及目标 | TCP 通不代表 REALITY 握手通过 |
| 浏览器通、CLI 不通 | 进程代理支持、端口协议、NO_PROXY、TUN、重启程序及认证 | 不能用浏览器出口代表 CLI |
| 401/403/429 | 具体响应、认证/权限/额度/频率，网络层单测 | 不直接等同于机房 IP 或封锁 |
| 多节点显示在线 | 显示来自面板还是客户端、时间窗口、探测、活动路由、流量差值 | 不能说其余节点绝不建立连接，探测也有流量 |
| 间歇断连 | 使用时段丢包/延迟、内存、重启、限额、证书续期、目的站 | 一次测速不证明长期稳定 |

低影响检查：

```powershell
Test-NetConnection -ComputerName <VPS_HOST> -Port <NODE_PORT>
```

```bash
sudo ss -lntp
systemctl status x-ui --no-pager
journalctl -u x-ui --since "10 minutes ago" --no-pager
```

只提取必要日志并遮盖秘密。内核可能由面板启动，独立 xray.service 不存在不代表故障。配置校验使用实际内核和对应命令，不假定 /usr/local/bin/xray 就是运行版本。

## 五个设备是否必须五个客户端

在无设备/IP 限制且客户端支持时，同一人的多设备可共用一个 UUID。需要按设备统计、限额或停用丢失设备时，才选择一设备一个。不同使用者推荐独立 UUID/订阅，便于撤销。

各客户端共享出口 IP、VPS 带宽和套餐总流量，不自动获得多份资源。额度按用途分配并留余量，不机械平分；确认上下行计费、单位和周期，面板统计可能与商家账单不同。

独立 UUID 隔离代理认证和计量，不保证目标站点风控互不影响。代理 UUID 不是应用账号，目标网站通常不直接接收该代理认证字段。

## 只导出一个使用者的配置

1. 找到该客户端，核对授权关联入站。
2. 复制该客户端自己的单节点链接/二维码或专属订阅；分配独立 Sub ID，不把整个入站批量导出发给同事。
3. 本地检查返回内容、UUID 与节点数量。一个人多个入站可以合法返回多条，与多个不同人的凭据混在一起不同。
4. 单入站单 UUID 场景用 `check_vless.py --expect-count 1`；检查器不联网下载订阅。由用户或已授权工具在本地获取，避免 Token 进入命令行/日志。
5. 通过用户指定的私密渠道交付。制作技能不授权代发同事；不分发面板账号、Token、私钥。

常见订阅结构为配置路径加 `subId`，当前官方代码按 Sub ID 获取客户端。**不要臆造 `?email=姓名` 过滤机制**，也不要猜订阅与面板共用端口；用实际生成的地址。

误把全部凭据导入一台设备时，保留自己的项，移除误导入项或换专属订阅，防止下次更新再次出现。确认泄露范围及授权后轮换受影响 UUID/Token，不无故轮换入站密钥。

## 撤销与泄露

- 停用个人：禁用其客户端，测试新连接被拒绝及其他人仍正常；已有连接是否断开需按实际版本验证。
- 订阅 Token 泄露：轮换可阻止继续获取，但已下载配置仍持有 UUID，需要按范围一并轮换 UUID。
- REALITY 私钥泄露：先准备所有受影响设备更新计划，再按授权切换入站密钥。
- 管理凭据出现在分享页：提示所有者凭据类别，建议撤销分享并轮换；不复述秘密，不登录“验证密码”。
